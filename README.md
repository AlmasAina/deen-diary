# Deen Say

Islamic calendar and daily routine tracker: namaz, 4 ayat tarjuma a day, tajweed (1 ruku × 3 days), period-aware streaks, rewards, a growing garden, tasks, to-do list and progress reports.

Live: https://almasaina.github.io/deen-diary/

- No server and no database: each person signs in with a name and 4-digit PIN on their own phone, and data stays in that phone's browser.
- Works offline after the first visit; use "Add to Home screen" to install it like an app.
- Backup tab exports/imports a JSON file.
